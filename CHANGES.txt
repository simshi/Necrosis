Necrosis - Changelog
====================

v8.8.5 (2026-08-30)
-------------------
Features:
  - Add "Force English language" option in Configuration > Messages
    * Players can now force addon UI display in English regardless of client language
    * Option available in all localized versions (EN, FR, DE, ES, RU, ZH, etc.)
    * Requires /reload to apply changes
    * Controlled via GetLocale() interception in PreLocales.lua

Bug Fixes:
  - Fix missing emotes on soulstone placement
    * Emotes tagged with <emote> are now properly triggered via DoEmote()
    * Handles variable replacement for player/target/pet names in emotes
    * Affects all languages (Speech files for EN, FR, DE, ES, RU, ZH, TW, MX)

Technical Changes:
  - Add PreLocales.lua module for locale forcing
  - Update all 11 TOC files to load PreLocales.lua before locale files
  - Improve MsgReplace() function in Message.lua to handle emote tags
  - Add FORCE_ENGLISH localization string to all 8 locale files

v8.8.4 (2026-08-27)
-------------------
Features:
  - TBC Anniversary 20506 compatibility

Bug Fixes:
  - Remove debug SetWidth(50) that made soulstone ovular
  - Use SetSize() instead of SetWidth/SetHeight for stone buttons

v8.8.3 (2026-08-25)
-------------------
Bug Fixes:
  - Anniversary addon bug fixes
  - Creature type checking with multi-locale variant support
  - Update creature type translations to official WoW values
